Catatan Penting: Bot ini hanya mendukung model AI dari Gemini saja saat ini.

Sebelum menjalankan program, anda wajib mengatur konfigurasinya terlebih dahulu:
- Masuk ke folder CypherBot ➔ backend.
- Buat file baru bernama .env di dalam folder backend tersebut.
- Buka file .env, lalu isi dengan format berikut:
  GEMINI_API_KEY=masukkan_api_key_gemini_kamu_di_sini
  (API Key bisa didapatkan secara gratis melalui Google AI Studio).
- Setelah file .env disimpan, kembali ke folder utama proyek (CypherBot).
- Cukup klik dua kali pada file runchatbot.bat untuk menjalankan program secara otomatis.
- Lakukan Sign Up / Log In dan CypherBot siap digunakan.

ENG:
Important Note: This bot only supports Gemini AI models at the moment.

Before running the program, you are required to set up the configuration first:
- Go to the CypherBot ➔ backend folder.
- Create a new file named .env inside that backend folder.
- Open the .env file, then fill it with the following format:
  GEMINI_API_KEY=paste_your_gemini_api_key_here
  (You can get the API Key for free via Google AI Studio).
- After saving the .env file, return to the main project folder.
- Simply double-click the runchatbot.bat file to run the program automatically.
- Sign Up / Log In and CypherBot is ready to use.
